# RoMoo io — roadmap

## 0.1 — Primeira versão jogável (estrutura inicial)
- [x] Projeto Rojo e configuração Luau
- [x] Terreno, recursos e ponto de surgimento gerados por script
- [x] Inventário temporário da sessão
- [x] Colheita e respawn de recursos
- [x] Ataque PvP validado pelo servidor
- [x] Paredes e armadilhas com custo e vida
- [x] Interface de teclado e toque
- [ ] Teste manual no Roblox Studio com 2 clientes

## 0.2 — Polimento / estabilidade
- [ ] Seleção precisa de alvo (em vez de só alvo próximo)
- [ ] Bandeja configurável de armas, itens e estruturas
- [ ] Mobile: HUD adaptável a diferentes aspect ratios
- [ ] Animais hostis, drops de comida, biomas
- [ ] Efeitos de coleta, ataque e destruição
- [ ] Testes automatizados para lógica de inventário/custos
- [ ] Limites e monitoramento do uso de servidor

## 0.3 — Progressão e online
- [ ] DataStore com fallback Studio, perfil versionado e retry
- [ ] Equipamentos e evolução de ferramentas
- [ ] Times / clãs e permissões de estruturas
- [ ] Proteção contra spawn killing
- [ ] Economia e rankings sazonais

## 0.4 — Pré-lançamento comercial
- [ ] Design original, identidade visual e acessibilidade
- [ ] Cosméticos / passes após validação da jogabilidade
- [ ] Revisão de retenção, monetização, desempenho e exploits
- [ ] Publicação e testes com jogadores reais

Não considerar um item concluído em produção sem teste efetivo no Studio.
